

# Manual Tester → GenAI Tester → AI Reliability Engineer

Manual testing alone is running out of runway. The roles that are hiring now — SDET, AI QA Engineer, LLM Evaluation Engineer, AI Reliability Engineer — all sit on top of an engineering base most manual testers never built.

Here's a roadmap by **@techwithprateek** that lays out that jump in 10 phases.

## The path


| Phase | Topic                                                         | Duration   |
| ------- | --------------------------------------------------------------- | ------------ |
| 1     | Programming Foundations (Python & Git)                        | 4–6 weeks |
| 2     | DSA for Test Engineers                                        | 4–6 weeks |
| 3     | Automation Testing Foundations (Playwright/Selenium + pytest) | 6–8 weeks |
| 4     | SQL & Backend Validation                                      | 2–3 weeks |
| 5     | CI/CD + DevOps Basics                                         | 4–5 weeks |
| 6     | System Design for Test Engineers                              | 5–7 weeks |
| 7     | AI Fundamentals                                               | 5–6 weeks |
| 8     | AI Testing & Evaluation                                       | 6–8 weeks |
| 8.5   | RAG Evaluation Deep Dive                                      | 3–4 weeks |
| 9     | AI Reliability Engineering                                    | 4–6 weeks |

**Timeline:** 6–9 months for the full path. Already an automation tester? Skip Phases 1–5, start at Phase 6, and you're through the GenAI track in ~12 weeks.

## Where you end up

- **Engineering:** Python, Git, SQL, APIs, DSA, Docker, CI/CD, system design
- **Automation:** Playwright/Selenium, pytest/JUnit, API and performance testing, observability
- **AI:** LLMs, RAG, agents, prompt engineering, multimodal, red teaming
- **Evaluation:** RAGAS, DeepEval, retrieval metrics, golden datasets, evals-in-CI

## The one piece of advice

Don't just consume tutorials.

> Learn → Build → Push to GitHub → Write README → Add to Portfolio

Projects and GitHub activity matter far more than certificates.
